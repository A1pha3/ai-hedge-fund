## 0. 目标函数（第一性原理）

1. 提高胜率和赔率的**陷阱答案**是少交易：砍掉任何低于均值的子集都会同时抬高两个指标。
   只有当被剔除的子集期望为**负**时，剔除才提高总增长。
2. 因此唯一正确的改进路径只有一类：**证明某个正在交易的子集期望为负 → 拒绝交易它**
   （等价地：只交易条件分布的正尾）。
3. 在位政策的剔除适用**非对称证据标准**：剔除在位正/零子集需要其转负的稳定证据；
   保留噪声子集的代价是可控的，错误剔除的代价是真实的。
4. per-trade E 与总量增长必须同时看：提均值毁总量的"改进"不是改进。

## 3. 否定面（不做什么）

1. 不直接优化胜率（卖保险即可做到 90% 胜率；代价藏在赔率里）。
2. 不让回测调参直通生产语义——一切行为变更走 证据包 → owner gate → 前向影子 → 政策。
3. 不绕过触发器/预注册机器——它就是正确答案的执行形态，改进 = 喂饱它、武装它。
4. 不在证据未武装时用"临场判断"替代规则（regime 闪烁期的手工开关是期望最差的形态）。

## 4. 决策纪律（全部杠杆共用）

- **预注册**：K、合取条件、启用/关闭规则一经注册不可回溯调整（改 = 新注册 + 新观测窗）。
- **合取武装**：单一条件不驱动行为变更；合取 + 机械武装后才进 owner 决策。
- **前向配对**：政策候选先影子（ Challenger 与 Champion 同窗配对），事后按配对证据评估。
- **单一实现**：判定包只装配既有单一实现（court 工具/触发器账本/exit_anatomy），不重算第二套。
