# 题材动量（Theme Momentum）Setup 设计

- 日期：2026-08-17
- 状态：**设计稿（Phase 0 未开始，无任何生产代码，不构成授权）**
- 触发案例：华正新材 603186（味之素 ABF 膜限售 → 国产替代叙事）。精确时间线（本地缓存验证）：8-03 大跌 −8.70% 收 98.60 → 8-04 超跌反包首板（前 5 日 −18.97%，电子行业 +5.73%，**被条件 2 挡**：主力净流出 −1.45 亿 < 20 日均值 −0.66 亿）→ 8-05 二板（四条件全过、生产 detect 重放 strength=0.79，**当日 --daily-action 未运行**）→ 8-07 第三板（条件 2+4 挡）→ 8-14 第四板（条件 2+4 挡）→ 8-17 第 5 个涨停日（非连板，8-11/8-13 曾下跌；外部信息，本地缓存尚无 8-17 数据）。本轮 8-03 收盘 → 8-14 收盘 167.55 = **+69.9%**
- 关联文档：`2026-04-29-btst-event-catalyst-design.md`（事件催化剂 = BTST 内部精修层，本文 = 独立 setup，边界见 §2）、`data/reports/cond2_gate_court_review_20260817.md`（条件 2 复核教训）

## 1. 动机与立论纪律

**立论不是"华正新材赚了 70% 我们没抓到"。** 单案例是幸存者叙事：8 月第一周全市场超跌后首板的票不止它一只，BTST 的 journal 执行口径期望是 T+10 +3.41%/57%（n=130），它只是样本里的右尾。用个案立论改参数是 AGENTS.md 明令禁止的路径（陷阱 19 的教训）。

**立论是：事件驱动的题材行情是一类可定义、可量化、可全候选回测的现象，而当前系统对它的覆盖只有"冷启动首板"一个切面。** A 股每年出现数十轮"催化剂 → 叙事共识 → 板块涨停潮 → 龙头连板 → 扩散/熄火"的完整周期；华正新材是其中一轮的正常样本。问题在于：

1. BTST 的条件 4（涨停前 5 日涨幅 ≤8%）按回测证据**有意排除**题材中继板——这没有错（中继板平均更差），但它意味着"题材确认后的延续段"整体落在系统覆盖之外；
2. 系统没有任何"题材强度"的量化数据链（概念板块涨停家数、板块涨幅榜、封板质量都不在缓存里），连"这类行情的事前分布是什么"都无法回答；
3. `--auto` 的 composite 是慢因子系统，此类票 shadow_rank #40~#197，永远进不了 Top10。

因此在写任何检测器之前，必须先能**回答**：题材延续段（第 2-N 板/板块内补涨）在全候选、执行口径下的 E[r]、胜率、凸性到底是不是正的？何种定义下是正的？本文档定义这个研究路径，而不是定义一个待上线的策略。

## 2. 与既有系统的边界（宪章约束）

| | BTST（现有） | 事件催化剂层（2026-04-29 设计） | 题材动量（本文） |
|---|---|---|---|
| 入场切面 | 冷启动首板（超跌/平台后） | 首板内的催化剂精修打分 | 题材**已确认后**的延续段（第 2-N 板、板块内跟随/补涨） |
| 宇宙 | 全市场涨停票 | BTST 候选子集 | 题材确认板块内的涨停票 + 前日涨停存活票 |
| 定位 | 生产 setup | BTST 边界 refiner（未实现） | **新 setup，从零证据起步** |

硬约束：
1. **不改 BTST、不动 regime gate**（court 证据 gated 1.430 vs ungated 1.133，gate 的价值不重议）；
2. 新 setup 是新的 producer 行为 → 按宪章 13 开新证据世代；在 Phase 1 court 回测 + Phase 2 前向 shadow 出具证据前，**不写任何生产检测器代码、不进 `--daily-action`**；
3. 样本宇宙必须与被评估现象一致（全候选，含退市者），**绝不使用 journal 成交子集**（陷阱 19）；
4. 执行合约与全系统统一：T0 收盘后决策、T+1 开盘买、一字锁死 = 不可成交（华正新材 8-05→8-06 gap +8.9% 未一字，执行可行——但这是个案，回测必须按 court 同款 fillable 语义统计可成交率）。

## 3. 第一性原理：题材行情的结构

一轮题材周期的可观测结构（全部要用数据回答，不预设答案）：

```
催化剂 (外部事件, T-1~T0)          ← 事前不可枚举, 只能事后观测
  → 叙事共识形成 (T0~T1): 板块首日涨停潮、板块涨幅榜进入前 3
  → 龙头确立 (T1~T2): 板块内首个涨停/最强封板/最高连板
  → 延续与扩散 (T2~TN): 龙头连板、板块内补涨、跟风票涨停
  → 熄火 (TN): 板块涨停家数骤降/龙头断板/炸板率飙升
```

可交易的假设（**每一条都是待检验假设，不是设计依据**）：

- H1（题材确认）：板块涨停家数 ≥ K 或板块涨幅进入当日前三的"确认日"之后，板块内涨停票的 T+1~T+5 期望为正；
- H2（龙头溢价）：确认日后，板块内连板数最高/封板最早的票优于跟风票（注意：streak 因子在"全部涨停票"总体上已被全量复核证伪——2026-08-08，2 连板胜率反低 4pp；H2 的总体是"已确认题材内的相对地位"，与裸连板不同，但先验必须按"很可能为假"对待）；
- H3（熄火可测）：板块涨停家数归零/龙头断板是有效退出信号，优于固定 T+N；
- H4（资金流无效）：东财主力净流入对延续段无区分度（2026-08-17 条件 2 复核：全候选 |t|<1.2、无单调性——本 setup 不预置任何资金流条件，除非未来证据翻转）。

## 4. 数据需求（Phase 0 的核心工作）

| 数据 | 来源（tushare 接口已存在） | 用途 | 风险 |
|---|---|---|---|
| 概念板块日行情 | `dc_daily`/`dc_index`（2020 起）、`ths_daily` | 题材确认（板块涨幅榜） | 东财/同花顺/开盘啦三套概念口径不一致，Phase 0 必须选一套并钉死版本 |
| 板块涨停家数 | `dc_concept.z_t_num`、`kpl_concept` | 确认/熄火信号 | 口径漂移；可用"行业内涨停家数"从 court lu 快照交叉验证 |
| 封板质量 | `limit_list_d`（first_time/open_times/up_stat）、`kpl_list` | 龙头识别、封板质量分 | 数据从 2022/2023 起，覆盖窗口需验证 |
| 题材→票映射 | `dc_member`/`kpl_concept_cons`（逐日成分） | 板块内候选 | 成分是动态的，必须用 as-of 成员（PIT），不得用最新快照回填历史 |

验收标准（Phase 0 完成的定义）：
1. 概念板块行情 + 逐日成分 + 涨停家数入库，窗口 ≥ 2025-07（与 court 对齐），PIT 语义与 price_cache/fund_flow_cache 同款（as-of 截断，绝不前视）；
2. 用 2026-08 华正新材案例做端到端 sanity check：ABF/国产替代相关板块在 8-04~8-07 的涨停家数、华正的板块内地位能否被数据正确复原；
3. 数据 manifest（来源、窗口、行数、缺口）入 `data/research/theme_momentum/`。

## 5. 检测器草案（v0，仅定义研究口径，不实现）

```
题材确认日 D*：板块 B 当日涨停家数(B, D) ≥ K₁  或  涨幅(B, D) 进入全板块前 3
               且 B 非纯防御性板块（银行等——用历史涨停家数分布排除，待定）
候选（D > D*，题材存活期内）：
  a) 板块内当日涨停票（跟随/补涨腿）
  b) 板块内前一日涨停、今日未跌停的存活票（龙头/延续腿）
排除：一字锁死（range<4%，court 语义 range_score=0.2 同源）、ST、次新(<60日)、
      价格<3、北交所
退出（对比四种，court 网格）：
  E1 固定 T+5 / E2 固定 T+8 / E3 题材熄火（板块涨停家数=0 或龙头断板）
  / E4 熄火或 T+8 先到
```

关键设计原则：
- **不预置资金流条件**（H4 已有 court 级反面证据）；
- **不预置连板加成**（streak 证伪教训），连板数只作为分组观测变量进事件表，等 Phase 1 分组证据说话；
- regime gate 沿用（crisis/risk_off 阻断新仓——court 已证）；
- 检测器输出的每个候选带全部诊断字段（板块内排名、封板时间、板块涨停家数、距确认日天数），供 Phase 1 分组归因，不只是 hit/miss。

          docs/superpowers/plans/2026-08-17-theme-momentum-research.md)
Phase 1  court 级全候选回放 (2025-07→今, T+1 open 执行口径)
         核心问题: 延续段 E[r]/胜率/凸性何时为正? (按确认强度/板内地位/距确认日
         天数分组; 主假设预注册唯一, 其余为探索性 — 多重比较防护)

每个 Phase 结束都允许"结论是不做"：Phase 1 若延续段全候选 E[r] ≤ 0（无论怎么分组），正确产出是关闭本方向的研究报告，不是调参到显著。

## 7. 已知风险与反方论证

1. **右尾依赖**：题材延续段大概率是"少数 +50% 覆盖多数 −10%"的分布——组合层面回撤远大于 BTST 首板，Kelly 会压到极低仓位；若 Phase 1 显示凸性 <1.5（BTST 的门槛值），直接否决；
2. **题材识别的事后偏差**：板块涨停家数是收盘后才知道的，作为"确认日"没有前视问题（T0 收盘决策/T+1 开盘买），但**板块定义本身**（哪个概念算"ABF/国产替代"）在数据源里是动态的——必须用 as-of 成分，Phase 0 验收专门查这一点；
3. **周期频率低**：2025-07→2026-08 约 1.2 个市场周期，完整题材周期样本可能只有 10~20 轮——统计功效天然不足，Phase 3 的 150 成熟 outcome 门槛可能需要 1~2 年前向累积才能达到，这是特性不是缺陷（系统不缺信号，缺的是可信信号）；
4. **与游资生态的对立面风险**：题材延续段的对手盘是散户跟风盘，监管窗口（特停、龙虎榜披露）会结构性改变分布——历史回测的外推有效性弱于技术性 setup，Phase 3 接入评估必须计入。

## 8. Non-Goals

1. 不改 BTST 任何条件（含条件 4 的防追高阈值——8-14 漏斗复算证明它是有效 gate）；
2. 不动 regime gate、Kelly、行业集中度等任何现有风控；
3. Phase 0/1 期间不写任何生产 `src/` 代码（研究脚本与数据入 `scripts/` + `data/research/theme_momentum/`）；
4. 不消费 journal 成交子集、不消费 `--auto` composite、不做"题材龙头 = 高分票"的循环论证；
5. 不设时间表承诺——Phase 推进只由证据质量决定。

## 9. 实现后的使用形态与接入路径（operator 视角，2026-08-18 补记）

本节回答"研究走完之后我怎么用、和现有策略什么关系"，供日后随时查阅。

### 9.1 三种结局，三种使用方式

| 结局 | 拿到什么 | 怎么用 |
|---|---|---|
| **关闭**（增量子集 T+8 ≤ −0.5pp） | 关闭报告 + 确认事件表 | 系统不变；事件表仍是可复用资产（见 9.4） |
| **统计不可判定**（周期样本 <15 或 CI 过宽） | "证据不足"记录 | 不推进也不关闭；窗口延长后按**原口径**复跑，禁止换参数复跑 |
| **做** | Phase 2 入场券 | 进入 9.2 流程——离进 `--daily-action` 还有数月 |

（第四分支"接近零"——增量子集 T+8 ∈ (−0.5pp, +0.65pp) 且 CI 含 0——是通往"做"的一次性救济：允许 Tier B 概念口径再试一次，不构成独立结局。）

先验提醒：BTST 自身证据（2 连板胜率反低 4pp、中继板更差）指向延续段偏负，本方向先验仅 20-35% 为真；Tier A/B 阳性后验也只 ~50-60%。**最可能的结局是第一行，廉价否证本身就是收获。**

### 9.2 "做"的最终形态：与 BTST 并存的第三个 setup，不是增强

```
--daily-action
├── BTST 涨停突破（T+10）     ← 冷启动首板（前 5 日涨幅 ≤8%）
├── OversoldBounce（T+5）     ← 默认暂停（无正 alpha 的前车之鉴）
└── 题材动量（T+N/熄火退出）  ← 新成员：题材确认后的第 2-N 板/板块内跟随票
```

**并存的具体含义**：同一组合、同一套风控全部继承（60% 组合上限、单票 10%、行业集中度、drawdown 熔断、regime gate、执行成本 v2.1）；但各有独立的候选宇宙、先验分布（Kelly 的 `known_distribution` 来自 Tier B 事件表回测）、退出合约（特色：题材熄火信号退出 vs 固定 T+N，Phase 1 配对检验决定）。

**operator 日常零变化**：收盘后 `--auto` → `--daily-action`，唯一可见差异是候选列表开始出现"第 2-N 板"的票（BTST 条件 4 本来排除的那类），每条信号带题材名、距确认日天数、板内地位和它自己的胜率/盈亏比先验。执行合约不变：T0 收盘决策、T+1 开盘买、开盘涨停自动放弃。

**为什么不是增强 BTST**：把题材条件塞进 BTST（如放宽条件 4 追高线）= 污染一个已被 8825 样本锁定的 setup，违反宪章 13（行为变化必须开新证据世代）。两个 setup 覆盖同段行情的不同切面、证据各自说话——OversoldBounce 是反面教材（概念混淆下用污染数据授权了加仓）。

### 9.3 时间线与各阶段 operator 能看到什么

```
本周         Tier A/B 出"做/不做"（执行计划 plans/2026-08-17）
             ↓ 若"做"
数月         Phase 2 前向 shadow：setup_output_log 同款逐日记录，不进 BUY 输出
             （纯观测；至少一个完整题材周期，含熄火样本）
             ↓ 证据够
6-12 个月    Phase 3 门槛（宪章 14：成熟 outcome 数/完整组合路径/与 BTST 容量重叠评估）
             ↓ 全达标
接入日       注册 verified setup → --daily-action 候选表出现新类信号
```

前向 shadow 的时长不是官僚拖延：题材周期一年只有几十轮且回测窗口内彼此相关，只有前向独立样本能把 ~50-60% 的后验推到可授权水平——"样本不能换 ID 复用"纪律的代价，也是没有第二个 OB 事故的原因。

### 9.4 无论结局如何都有的副产品增强路径

1. **BTST 条件 3 升级候选**：现行板块效应度量是"行业指数涨幅 >2%"，研究的"行业涨停占比跳变"是更强的度量——改 BTST 任何条件须 court 级 A/B（如 2026-08-17 对条件 2 的复核），事件表直接提供数据基础。
2. **`--auto` event_sentiment 输入**：概念确认事件是比个股稀疏新闻强得多的结构化事件源，可提升此类票 shadow_rank。

### 9.5 一句话备忘

现在批准的计划买到的是**判决书**（值不值得建第三个 setup）；判决为"做"，未来某天的 `--daily-action` 里多一类与 BTST 并列、共享风控、独立证据的信号；无论判决如何，事件表已让 BTST 条件 3 与 event_sentiment 两处现有系统有了升级弹药。
